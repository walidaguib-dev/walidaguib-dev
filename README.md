## 🏆 Featured Projects

### 1. CargoPin — GPS Cargo Positioning System
> *Reduced cargo location time from 20 minutes to 3 seconds*

[![CargoPin](https://img.shields.io/badge/CargoPin-Repo-blue)](https://github.com/walidaguib-dev/CargoPin)
[![Live API](https://img.shields.io/badge/Live_API-green)](https://cargopin-production.up.railway.app)

GPS-based cargo tracking system for port merchandise with real-time mapping.

**Key Features:**
- PostGIS spatial queries (`ST_Contains`) for automatic zone/area classification
- Real-time updates with SignalR WebSockets
- GeoJSON API for map rendering
- Clean Architecture + CQRS + MediatR
- Deployed on Railway with PostgreSQL

**Tech Stack:** ASP.NET Core 10, PostgreSQL + PostGIS, Redis, SignalR, Docker

### 2. Tally API — Port Operations Management
> *Production API with 100+ endpoints*

[![Tally API](https://img.shields.io/badge/Tally_API-Repo-blue)](https://github.com/walidaguib-dev/Tally-App)

**Key Features:**
- 100+ endpoints with Clean Architecture + CQRS + MediatR
- Write-behind caching: Redis → Hangfire → PostgreSQL

- Deployed on Railway with Docker
